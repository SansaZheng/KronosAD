# 无监督金融异常检测实验协议 v1

本协议在查看本轮模型测试成绩前固定。模型训练、预处理、训练抽样、阈值拟合、训练步数均不使用异常标签；源标签只用于最后评价和报告数据组成。不依据测试成绩重新选择特征、阈值或模型。

## 方法与适用边界

1. **Kronos-mini 特征自编码适配器**：新实验方法。将一个特征向量映射为一个连续 token，经冻结的 Kronos-mini 4 层 Transformer 和最终 RMSNorm，再由线性层重构特征。输入编码器为 `F→min(8,max(1,F//2))→tanh→256`；编码器和重构层可训练。原 tokenizer、token embedding、时间 embedding、生成头不参与计算。
2. **随机骨干适配器**：同结构、同种子初始化的输入与输出层；骨干使用随机初始化并冻结，用于检查预训练权重的作用。
3. **Isolation Forest**：100 棵树、每棵最多 256 个训练样本。评分为 `-score_samples`，越高越异常。

第一种方法不是原版 Kronos OHLC 预测误差检测器。单 token 无跨时间注意力，不能用本实验声称其具备时间序列预测优势，也不能把其结果冠以“原版 Kronos 零样本表现”。不伪造 OHLC，不把欺诈等同于价格预测偏差。预训练迁移是否有效，以随机骨干对照的实测结果为准。

对适配后的特征向量 `z`，分数为 `s=mean((z-decoder(KronosBlocks(encoder(clip(z)))))**2)`，判定为 `y=1[s>=POT(calibration_scores)]`。一个样本可以对应一笔交易、一个原始时间点或一个完整序列，取决于该数据标签粒度；本轮不把序列标签展开成点标签。数据未提供异常维度真值，因此不报告维度诊断的准确率。

## 固定训练与评分

- 每个数据集、每个方法使用种子 42、43、44；数据划分固定。不同种子的均值与总体标准差（ddof=0）反映训练随机性，不是置信区间。
- 从训练分区均匀无放回抽取最多 50,000 行；不筛选正常标签，不做类别平衡。保留训练污染。测试使用全部留出行，不抽样、不过采样、不平衡类别。
- 仅训练抽样拟合有效特征、缺失值中位数和缩放。优先 IQR/1.349；IQR 退化时用训练标准差，再退化则用 1。训练中全缺失的列删除；训练中出现缺失的列追加缺失指示变量。评估数据不改变这些参数。
- 适配器 AdamW，学习率 0.001，weight decay 0.0001，固定 400 步，batch 最多 256，有放回训练采样；不使用标签早停或验证集选模型。骨干始终 eval，所有骨干参数冻结。
- 模型输入限制在标准化后的 [-8,8]；适配器使用对同区间目标的 smooth L1 损失。适配器异常分数为**未截断**标准化观测与重构值的均方误差。Isolation Forest 使用同一预处理并截断输入。
- 从独立校准分区均匀无放回抽取最多 100,000 行，拟合**单一聚合分数**的固定 POT；初始分位数 0.85、risk=0.01、至少 20 个非退化峰值。0.85 为使 TSTR 的 193 个校准序列仍有足够峰值预先指定，不按 F1 选择。此处不是原 OHLC 方法逐维 Bonferroni POT，也不是在线 SPOT。拟合失败明确记录，不暗中切换阈值。
- `score >= threshold` 触发异常。训练、校准函数不接收标签；阈值写入文件后才打开测试标签。校准污染和分布漂移可能使实际误报率远高于名义 risk。

## 数据划分与特征

| 数据 | 固定分区 | 特征及评价单位 |
| --- | --- | --- |
| Sapienza | 沿用已发布的币种分组 60/20/20，默认 15S | 原始 12 维工程特征；起点块级，未扩展为完整事件标签 |
| TSTR | 沿用去重后序列分组 | 全段收益统计、分位数、滚动收益均值/标准差最大值，共 20 维；整段序列评价，不生成点标签 |
| SD-FMM stock/crypto | 沿用源序列分组 | 原值、差分和过去/当前 4、16、32 点的均值、标准差、极差，共 11 维；点级评价，序列边界不串接 |
| ULB | Time≤86400 / ≤129600 / 其后 | V1..V28 与 signed-log Amount，29 维；不含 Time、Class |
| Elliptic | 时间步 1..29 / 30..34 / 35..49 | 原 165 维节点特征；不使用图边。未知标签节点参与无标签训练/校准，最后评价只统计已知标签 |
| PaySim | 仅读 step 的预扫描，按累计行数 60%/80% 的时间边界划分，同一 step 不拆开 | log amount、两个旧余额、交易类型 one-hot；排除账号、事后余额、isFlaggedFraud |
| TabFormer | Year≤2016 / 2017 / ≥2018 | 金额、月、日、分钟周期、错误/缺失指示、Use Chip 和 MCC 的固定 SHA256 one-hot 哈希；排除用户/卡/商户 ID |
| AML HI-Small | 仅读 Timestamp 的预扫描，按累计行数 60%/80% 的时间边界划分，同一分钟不拆开 | 收付金额、同银行/同币种、币种/支付方式的固定哈希；排除账号和洗钱模式标注文件 |
| IEEE-CIS | 仅官方有标签训练表，TransactionDT≤9504000 / ≤12614400 / 其后 | 数值交易字段；排除 ID、DT、目标和明确字符串类别列；本轮不接身份表。官方测试无真值，不计算其指标 |

TSTR 原分组含按标签分层的历史准备步骤，训练本身不访问标签。TSTR 训练/校准约半数为正，严重违背稀有异常假设，其结果需单独解释。SD-FMM 是出版者已处理的完整序列数据，存在全段归一化和样本身份缺失等限制；本轮重用公开 test 文件做研究划分，不能与论文原零样本成绩直接比较。TSTR 全段统计是回顾性分析，不是实时发现。Elliptic 原聚合特征可能包含后续邻居，不构成实时反洗钱验证。支付欺诈不必然是特征分布离群，须接受实际低召回结果。

数据准备阶段发现合成数据在名义时间范围内的交易量极不均匀，因此在任何训练或模型测试前，将 PaySim、AML 的日历比例分区改为以上**无标签时间计数边界**；其余数据不变。边界值与实际分区大小保存于数据 manifest。此调整不依据模型指标，不按异常比例选择边界。

原有市场数据分区保持不变；交易数据严格按时间边界分区，但同一账户可跨时间出现，属于未来交易泛化，不声称未见账户泛化。原始记录的重复、跨来源事件重叠和上游预处理无法全部排除，本轮不作跨数据集独立性或统计显著性结论。

## 指标与交付

报告 TP、FP、FN、TN、Precision、Recall、F1、FPR、ROC-AUC、Average Precision（AP，作为主要 PR 曲线汇总指标）和梯形积分 PR-AUC。AP 与梯形 PR-AUC 分列，避免混称。无 point adjustment，不根据测试标签遍历阈值，不把准确率作为主要指标。不同粒度/真实与合成数据不做跨数据集宏平均排行。

每次运行保留环境、权重 SHA256、训练索引、预处理参数、训练损失、POT 参数、完整留出评分及哈希。仅将聚合结果和方法文档提交 GitHub；缓存、模型和逐行输出放在 `.local_data/`。IEEE 原始文件和逐行结果保持本地受限。

复现：

```bash
python -m pip install -r requirements-benchmark.txt
python -m benchmarks.data --cache .local_data/unsupervised_v1 \
  --ieee-dir /path/to/locally-authorized-ieee-data
python -m benchmarks.run --cache .local_data/unsupervised_v1 \
  --output .local_data/unsupervised_runs_v1 --weights weights/Kronos-mini \
  --device cpu
```

无本地 IEEE 授权数据时，`--datasets` 中省略 `ieee_cis`；原权重需按离线模型说明准备。可在支持的机器上设置 `--device mps` 或 `cuda`，不同硬件不保证逐位一致。
